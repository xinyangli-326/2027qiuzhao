# 2027届秋招信息汇总（含国央企 · 支持自定义岗位方向）

网页版秋招公司清单与投递进度追踪表。收录已开放 2027 届秋招（含提前批）的公司，覆盖大厂 / 中厂 / AI 中厂 / 小厂 / 快消 / 化妆品 / 餐饮茶饮 / 服装服饰 / 房地产 / 金融 / 央企国企 / 汽车 / 能源 / 家电 / 医药 / 教育 / 物流等行业（不收录银行）。

## 功能

- 按公司分类筛选；按职业方向（AI产品 / 产品经理 / 产品运营 / 运营 / 市场品牌 / 电商零售 / 游戏 / 数据 / 供应链 / 管培等）组合筛选
- “我的求职方向”自定义输入：可输入“财务 会计”“人力 行政”“法务”“营销 品牌”等岗位 / 职能关键词，反向筛出开放相关岗位的公司（例如财务方向可筛出中国移动、中国电信、中国太平、华润置地（百匠新人/万象生）、保利发展等）
- 没有校招官网入口但已确认开放的公司同样收录，“投递入口 / 投递方式”列会直接标注公众号名称、简历邮箱或宣讲会现场投递等渠道（例如中国铁建港航局：公众号“中国铁建港航局”+ 邮箱投递）
- 每家公司记录开启时间、相关岗位方向、投递入口与信息来源
- 选择投递状态后自动记录当天日期（已投递 / 笔试 / AI面试 / 面试 / 流程结束），形成进度时间线，可一键把某个环节更新为今天
- 导出 CSV、备份 / 恢复 JSON
- 页面内“检查更新”可提示数据是否有新版本

## 隐私说明

- 本仓库只包含各公司公开的秋招信息（公司名、公开岗位描述、官网 / 招聘页链接等），不包含任何个人简历或求职进度数据
- 投递进度与日期记录仅保存在访问者自己的浏览器 localStorage 中，不上传、不存储到任何服务器或 GitHub
- 访问者之间互不影响：各自浏览器里看到和保存的是各自的进度

## 数据更新

公司列表与岗位信息由人工收集整理；更新时直接修改 `index.html` 内的数据并同步 `version.json` 的版本号后推送即可，在线页面点击“检查更新”即可发现新版。
